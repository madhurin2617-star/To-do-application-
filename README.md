# 📝 To-Do Application

A simple and user-friendly command-line To-Do Application developed using Python. It helps users manage daily tasks by adding, viewing, completing, and deleting tasks.

## 🚀 Features

- **Add Tasks:** Add new tasks to your to-do list.
- **View Tasks:** Display all available tasks.
- **Complete Tasks:** Mark tasks as completed.
- **Delete Tasks:** Remove tasks you no longer need.
- **File Handling:** Store tasks in a file for future use.

## 🛠️ Technologies Used

- Python 3
- File Handling
- Command-Line Interface (CLI)

## 📂 Project Structure

```text
To-do-application/
├── todo.py
├── tasks.txt
└── README.md
```

*Note: The `tasks.txt` file is required only if your program uses it to store tasks.*

## ⚙️ Requirements

- Python 3 installed on your system.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the following command:

```bash
python todo.py
```

If your system uses the Python launcher, you can run:

```bash
py todo.py
```

## 🎯 Project Objective

The objective of this project is to simplify daily task management while demonstrating Python programming concepts, functions, conditional statements, loops, and file handling.
